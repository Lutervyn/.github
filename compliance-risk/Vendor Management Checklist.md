# Vendor Management Checklist

Last Updated: May 12, 2026

## 1. Pre-Engagement (Due Diligence)

- [ ] **Business Need**: Define the specific problem the vendor solves.
- [ ] **Market Research**: Compare at least 2-3 vendors for price and features.
- [ ] **Financial Stability**: Review vendor's financial health (if significant contract).
- [ ] **Security Review**:
  - [ ] SOC2 Type II report or equivalent.
  - [ ] Security questionnaire completed.
  - [ ] Penetration test results (if applicable).
- [ ] **Compliance Check**:
  - [ ] GDPR/Privacy compliance verified.
  - [ ] Sanctions/Watchlist screening.

## 2. Contracting & Legal

- [ ] **Legal Review**: Contract reviewed by Legal team.
- [ ] **Data Processing Agreement (DPA)**: Signed if vendor handles personal data.
- [ ] **Service Level Agreement (SLA)**: Clear uptime and support commitments.
- [ ] **Termination Clauses**: Clear path to exit if service is poor.
- [ ] **Insurance**: Proof of relevant insurance (Cyber, Liability).

## 3. Onboarding & Implementation

- [ ] **Technical Setup**: Integration with Lutervyn systems.
- [ ] **Access Management**:
  - [ ] SSO integration where possible.
  - [ ] Principle of Least Privilege (PoLP) applied.
- [ ] **Documentation**: Internal guide on how to use/manage the vendor tool.
- [ ] **Team Training**: Ensure relevant staff know how to work with the vendor.

## 4. Ongoing Management

- [ ] **Performance Monitoring**: Regular check of SLAs and service quality.
- [ ] **Billing Audit**: Verify invoices match contracted rates.
- [ ] **Quarterly Review**: Strategic sync for high-value vendors.
- [ ] **Risk Re-assessment**: Annual review of security/compliance status.

## 5. Offboarding (Termination)

- [ ] **Data Retrieval**: Ensure all Lutervyn data is exported.
- [ ] **Data Deletion**: Certificate of deletion from vendor.
- [ ] **Access Revocation**: Remove all vendor user accounts and API keys.
- [ ] **Final Payment**: Settle all outstanding invoices.
- [ ] **Contract Archiving**: Mark as "Terminated" in the Contract Management System.
