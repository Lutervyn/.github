# Code Review Checklist

Last Updated: May 12, 2024

## 1. Functionality

- [ ] Code solves stated problem
- [ ] All requirements met
- [ ] No incomplete features
- [ ] Works as intended
- [ ] Edge cases handled
- [ ] Error handling proper
- [ ] No hardcoded values

## 2. Code Quality

- [ ] Follows style guide
- [ ] Naming conventions
- [ ] Functions reasonably sized
- [ ] Comments clear and current
- [ ] No code duplication
- [ ] Proper abstraction
- [ ] Maintainable code

## 3. Testing

- [ ] Unit tests provided
- [ ] Test coverage adequate
- [ ] Tests pass
- [ ] No test regressions
- [ ] Edge cases tested
- [ ] Happy path tested
- [ ] Error cases tested

## 4. Performance

- [ ] No obvious inefficiencies
- [ ] Algorithms appropriate
- [ ] Database queries optimized
- [ ] Memory usage acceptable
- [ ] No memory leaks
- [ ] Response times acceptable

## 5. Security

- [ ] No hardcoded secrets
- [ ] No SQL injection risk
- [ ] Input validation present
- [ ] Authorization checked
- [ ] Authentication required
- [ ] No sensitive data exposed
- [ ] Dependencies updated

## 6. Documentation

- [ ] Code commented
- [ ] Readme updated
- [ ] API documented
- [ ] Examples provided
- [ ] Changelog updated

## 7. Compatibility

- [ ] No breaking changes
- [ ] Backward compatible
- [ ] Works on supported versions
- [ ] Cross-browser tested
- [ ] Mobile responsive
