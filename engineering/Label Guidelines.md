# Issue Label Guidelines

Last Updated: May 12, 2024

## 1. Type Labels

- **type-bug**: Bug report
- **type-feature**: Feature request
- **type-enhancement**: Enhancement
- **type-docs**: Documentation
- **type-question**: Question

## 2. Priority Labels

- **priority-critical**: Urgent, production
- **priority-high**: Important, soon
- **priority-medium**: Standard
- **priority-low**: Nice to have

## 3. Status Labels

- **status-triage**: Needs review
- **status-approved**: Ready for work
- **status-in-progress**: Being worked on
- **status-blocked**: Waiting on something
- **status-needs-review**: Review requested
- **status-done**: Complete

## 4. Effort Labels

- **effort-small**: <4 hours
- **effort-medium**: 4-8 hours
- **effort-large**: 8-16 hours
- **effort-epic**: >16 hours

## 5. Help Labels

- **help-wanted**: Community contribution
- **good-first-issue**: New contributor friendly
- **needs-info**: More info required

## 6. Area Labels

- **area-api**: API related
- **area-ui**: UI/Frontend
- **area-backend**: Backend
- **area-database**: Database
- **area-security**: Security
- **area-docs**: Documentation
