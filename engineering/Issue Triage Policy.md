# Issue Triage Policy

Last Updated: May 12, 2024

## 1. Triage Process

### 1.1 Initial Review

1. Issue received
2. Title and description reviewed
3. Category assigned
4. Priority determined
5. Assignment set
6. Status set to "triage"

### 1.2 Priority Levels

- **Critical**: Production down, data loss
- **High**: Major functionality broken
- **Medium**: Feature partially broken
- **Low**: Minor issues, cosmetic

### 1.3 Categories

- Bug: Malfunction
- Feature: New capability
- Enhancement: Improvement
- Documentation: Doc issue
- Question: Clarification

## 2. Labels

- priority-critical
- priority-high
- priority-medium
- priority-low
- type-bug
- type-feature
- help-wanted
- good-first-issue

## 3. Assignments

- Assigned to appropriate team
- Technical expertise required
- Capacity considered
- Rotation maintained
- Clear expectations

## 4. Response Times

- Critical: 4 hours
- High: 1 day
- Medium: 3 days
- Low: 1 week
- Acknowledgment sent

## 5. Contact

- Triage: triage@lutervyn.com
- Issues: issues@lutervyn.com
