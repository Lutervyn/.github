# Internal Audit Policy

Last Updated: May 12, 2024

## 1. Purpose

Regular internal audits assess compliance with security and operational policies.

## 2. Audit Scope

### 2.1 Coverage

- Security controls
- Access management
- Data protection
- Incident response
- Vendor management
- Compliance adherence
- Policy effectiveness

### 2.2 Frequency

- Critical systems: Quarterly
- Important systems: Semi-annual
- Standard systems: Annual
- Policy review: Annual
- Compliance check: Quarterly
- Continuous monitoring

## 3. Audit Process

### 3.1 Planning

1. Audit scope defined
2. Objectives set
3. Timeline established
4. Resources allocated
5. Notifications sent
6. Preparation completed

### 3.2 Execution

1. System review
2. Controls tested
3. Documentation examined
4. Interviews conducted
5. Testing performed
6. Evidence collected
7. Findings documented

### 3.3 Reporting

1. Report drafted
2. Findings included
3. Recommendations provided
4. Risk assessment
5. Management response
6. Timeline established
7. Follow-up scheduled

## 4. Findings Management

### 4.1 Classification

- Critical: Immediate action
- High: Within 30 days
- Medium: Within 90 days
- Low: Within 6 months
- Observations: Best practice

### 4.2 Resolution

1. Root cause analysis
2. Corrective action
3. Implementation timeline
4. Responsibility assigned
5. Progress tracked
6. Verification completed
7. Closure verified

## 5. Audit Reports

### 5.1 Content

- Executive summary
- Audit scope
- Methodology
- Findings
- Recommendations
- Management response
- Timeline

### 5.2 Distribution

- Management
- Finance
- Compliance
- Board (annually)
- Stakeholders
- Regulators (as required)
