# Data Classification Policy

Last Updated: May 12, 2024

## 1. Purpose

Classifies data by sensitivity to determine appropriate handling and protection.

## 2. Classification Levels

### 2.1 Public
- No sensitivity
- Publicly available
- Marketing materials
- Published documents
- Blog posts
- Minimal protection

### 2.2 Internal
- Limited distribution
- Employee information
- Internal procedures
- Policies and standards
- Project information
- Standard protection

### 2.3 Confidential
- Restricted access
- Customer data
- Business strategy
- Financial information
- Pricing
- Strong protection required

### 2.4 Restricted
- Highly sensitive
- Personal information (PII)
- Payment card data
- Health information
- Trade secrets
- Maximum protection

## 3. Protection Requirements

### 3.1 Public Data
- No encryption required
- No access controls
- Public storage acceptable
- Standard backups
- No special monitoring

### 3.2 Internal Data
- Encryption recommended
- Access controls: Department level
- Secure storage
- Monitored access
- Audit logging

### 3.3 Confidential Data
- Encryption required
- Access controls: Need-to-know
- Secure storage
- Encrypted backups
- Detailed audit logging

### 3.4 Restricted Data
- Encryption mandatory
- Strict access controls
- Segregated storage
- Encrypted transport
- Comprehensive monitoring
- Regular audits

## 4. Handling Guidelines

### 4.1 Retention
- Public: No limit
- Internal: 3 years
- Confidential: Per agreement
- Restricted: Minimal time

### 4.2 Disposal
- Public: Standard deletion
- Internal: Secure deletion
- Confidential: Encrypted deletion
- Restricted: Destruction certificate

### 4.3 Sharing
- Public: Freely shareable
- Internal: Internal only
- Confidential: With permission
- Restricted: Never external

## 5. Classification Process

1. Data owner assigns
2. Based on content
3. Documented classification
4. Reviewed annually
5. Updated as needed
6. Training provided
