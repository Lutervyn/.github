# IT Asset Management Policy

Last Updated: May 12, 2024

## 1. Purpose

Manages tracking, security, and lifecycle of all IT assets.

## 2. Asset Categories

### 2.1 Hardware
- Computers (desktop/laptop)
- Servers
- Network equipment
- Mobile devices
- Peripherals
- Networking devices

### 2.2 Software
- Operating systems
- Applications
- Licenses
- Cloud services
- SaaS subscriptions
- Development tools

### 2.3 Infrastructure
- Servers
- Storage systems
- Network infrastructure
- Security systems
- Backup systems
- Disaster recovery

## 3. Asset Lifecycle

### 3.1 Procurement

1. Request submitted
2. Approval obtained
3. Order placed
4. Received and inspected
5. Registered in system
6. Configured and deployed
7. Assigned to user

### 3.2 Maintenance

1. Regular updates
2. Patches applied
3. Performance monitored
4. Repairs conducted
5. Upgrades planned
6. Issues tracked

### 3.3 Disposal

1. End-of-life determined
2. Data removal
3. Secure destruction
4. Deregistration
5. Documentation
6. Recycling/disposal

## 4. Inventory Management

### 4.1 Tracking

- Asset register maintained
- Serial numbers recorded
- Owner assigned
- Location tracked
- Condition noted
- Value recorded

### 4.2 Audits

- Annual physical audit
- Inventory reconciliation
- Discrepancies investigated
- Theft prevention
- Lost item tracking
- Missing asset procedure

## 5. Security Requirements

### 5.1 Hardware

- Full disk encryption
- Secure boot enabled
- Firmware updates
- BIOS password
- Physical lock
- Tracking installed

### 5.2 Software

- Licensed properly
- Supported versions
- Regular updates
- No unauthorized installations
- Compliance verified
- Usage monitored

## 6. Device Management

### 6.1 Configuration

- Standard image deployed
- Security hardened
- Antivirus installed
- Firewall enabled
- Monitoring enabled
- Baseline established

### 6.2 Monitoring

- Endpoint monitoring
- Performance tracked
- Security alerts
- Compliance checked
- Issue resolution
- Reporting generated
