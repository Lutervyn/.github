# Cyber Hygiene Guidelines

Last Updated: May 12, 2024

## 1. Passwords

### 1.1 Requirements

- Minimum 12 characters
- Mix of character types
- No dictionary words
- No personal information
- Unique passwords
- Change every 90 days

### 1.2 Management

- Password manager required
- KeePass, 1Password, LastPass
- Master password: very strong
- No sharing passwords
- No writing down
- No reuse

## 2. Multi-Factor Authentication

### 2.1 Requirement

- MFA mandatory for all accounts
- Work systems
- Email accounts
- Cloud services
- Administrative access
- Critical systems

### 2.2 Methods

- TOTP (Time-based One-Time Password)
- U2F security keys preferred
- SMS as backup only
- Authenticator apps
- Backup codes stored

## 3. Device Security

### 3.1 Endpoint Security

- Antivirus installed
- Firewall enabled
- Auto-updates enabled
- Full disk encryption
- Screen lock (auto 5 min)
- Device tracking

### 3.2 Mobile Devices

- MDM enrollment required
- Pin/Biometric lock
- App encryption
- Remote wipe capability
- Device tracking
- Approved apps only

## 4. Email Security

### 4.1 Best Practices

- Don't click suspicious links
- Verify sender email
- Be cautious with attachments
- Report phishing immediately
- Use digital signatures
- Encrypt sensitive email

### 4.2 Anti-Phishing

- Training annually
- Simulations monthly
- Report to security@
- Investigation conducted
- Awareness increased
- Feedback provided

## 5. Software Updates

### 5.1 Patching

- Critical: Within 24 hours
- Important: Within 1 week
- Standard: Within 1 month
- Beta/test: As feasible
- Automatic where possible
- Manual tracking otherwise

### 5.2 Deprecation

- Unsupported software removed
- Legacy systems phased out
- Upgrades planned
- Support windows tracked
- Replacements identified

## 6. Data Handling

### 6.1 Principles

- Minimize collection
- Secure storage
- Limited access
- Regular deletion
- No unnecessary copying
- Encrypted transfers

### 6.2 USB/External Media

- Use only approved devices
- Encrypt all data
- No personal devices
- IT managed only
- Tracked inventory
- Destroyed securely

## 7. Network Security

### 7.1 Wi-Fi

- Corporate Wi-Fi only
- VPN if unsecured
- No public Wi-Fi for work
- WPA2/WPA3 encryption
- Certificate validation
- No password sharing

### 7.2 VPN

- Mandatory for remote work
- Company VPN only
- Always-on configuration
- Split tunneling disabled
- Encryption: AES-256
- Certificate pinning

## 8. Physical Security

### 8.1 Workspace

- Lock computer when away
- Secure sensitive documents
- No tailgating
- Visitor badges
- Facility access controls
- Badge access logging

### 8.2 Supplies

- Secure document disposal
- Shred confidential papers
- Locked cabinet storage
- Clean desk policy
- No document abandonment

- Annual mandatory
- New employee: First week
- Ongoing awareness

- Compliance tracking
