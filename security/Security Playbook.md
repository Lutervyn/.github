# Security Playbook

Last Updated: May 12, 2024

## 1. Purpose

Step-by-step procedures for common security scenarios.

## 2. Incident Response

### 2.1 Initial Response

1. Stay calm
2. Do not panic
3. Contact security immediately
4. Email: security@lutervyn.com
5. Or call: [Emergency Phone]
6. Provide details
7. Follow guidance

### 2.2 Containment

1. Isolate affected system
2. Disconnect from network
3. Preserve evidence
4. Do not shut down
5. Document timeline
6. Notify management
7. Activate response team

### 2.3 Investigation

1. Secure affected system
2. Collect evidence
3. Analyze logs
4. Interview affected parties
5. Determine scope
6. Root cause analysis
7. Document findings

## 3. Suspicious Activity

### 3.1 Recognition

- Unusual login times
- Unexpected account activity
- Strange file access
- Unusual network traffic
- Unauthorized changes
- Unfamiliar processes

### 3.2 Response

1. Do not alert suspect
2. Contact security
3. Preserve evidence
4. Gather information
5. Investigation proceeds
6. Possible involvement
7. Legal involvement

## 4. Password Compromise

### 4.1 Discovery

1. Change password immediately
2. Contact security
3. Review account activity
4. Check for unauthorized access
5. Monitor account

### 4.2 Recovery

1. Account reset forced
2. MFA re-enabled
3. Session termination
4. Password forced change
5. Activity monitoring
6. Investigation ongoing

## 5. Phishing Attack

### 5.1 Identification

- Suspicious sender
- Urgent language
- Unusual request
- Suspicious link
- Attachment warning
- Grammar errors

### 5.2 Response

1. Do not click links
2. Do not open attachments
3. Do not reply
4. Forward to phishing@lutervyn.com
5. Report to manager
6. Delete email
7. Monitor account

## 6. Malware Detection

### 6.1 Signs

- System slowdown
- Unexpected pop-ups
- Files disappearing
- Network activity
- Strange behavior
- Disk activity

### 6.2 Actions

1. Disconnect from network
2. Power off system
3. Contact IT immediately
4. Do not attempt removal
5. System quarantine
6. Professional recovery
7. Investigation

## 7. Data Loss Prevention

### 7.1 Backup

1. Regular backups automated
2. Test restore monthly
3. Off-site copies maintained
4. Multiple copies stored
5. Encryption verified
6. Integrity confirmed

### 7.2 Recovery

1. Backup identified
2. Restore point selected
3. Recovery initiated
4. Verification conducted
5. Service restored
6. Data validated

## 8. Third-Party Breach

### 8.1 Notification

1. From vendor received
2. Assessment conducted
3. Impact determined
4. Customers notified
5. Remediation planned
6. Monitoring increased

### 8.2 Actions

1. Stop using if needed
2. Change credentials
3. Monitor accounts
4. Request details
5. Evaluate alternative
6. Possible termination
