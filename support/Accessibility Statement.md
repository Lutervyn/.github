# Accessibility Statement

Last Updated: May 12, 2024

## Commitment

Lutervyn is committed to accessibility for all users.

## Standards

- WCAG 2.1 Level AA
- ADA compliance
- Section 508 compliance
- Continuous improvement

## Features

### 1. Vision

- Sufficient color contrast
- Resizable text
- Text alternatives
- High contrast mode
- Zoom support

### 2. Motor

- Keyboard navigation
- No mouse required
- Large clickable areas
- Voice control support
- Accessible controls

### 3. Hearing

- Captions and transcripts
- Visual indicators
- No sound-only content
- Adjustable volume
- Text alternatives

### 4. Cognitive

- Clear language
- Simple navigation
- Consistent design
- Help available
- Error prevention

## Tools and Testing

- Accessibility scanner
- Screen reader testing
- Manual review
- User testing
- Third-party audit

## Reporting Issues

Found an accessibility issue?

Email: accessibility@lutervyn.com

Include:
- Issue description
- Device/browser
- Steps to reproduce
- Impact on usage

## Improvements

Recent improvements:
- Enhanced keyboard navigation
- Improved color contrast
- Added captions
- Better screen reader support
