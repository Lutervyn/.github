# API Service Level Agreement (SLA)

Last Updated: May 12, 2024

## 1. Service Availability

### 1.1 Uptime Target

- **Free**: 99% uptime
- **Pro**: 99.5% uptime
- **Enterprise**: 99.9% uptime

### 1.2 Measurement

- Measured monthly
- Calculated from monitoring
- Excludes planned maintenance
- Excludes customer issues

## 2. Response Time

### 2.1 Targets

- **Average**: <200ms
- **P95**: <500ms
- **P99**: <1000ms

### 2.2 Measurement

- Global average
- From multiple locations
- API response time
- Excludes network latency

## 3. Error Rate

### 3.1 Target

- **Free**: <1% error rate
- **Pro**: <0.5% error rate
- **Enterprise**: <0.1% error rate

### 3.2 Definition

- Errors: 5xx responses
- Excludes 4xx responses
- Excludes rate limiting

## 4. Credits

### 4.1 Uptime Credits

- 99-99.5%: 10% credit
- 99-98.5%: 25% credit
- <98.5%: 50% credit

### 4.2 Request

- Must claim within 30 days
- Automatic if enterprise
- Applied to next invoice

## 5. Exclusions

- Planned maintenance (24h notice)
- Customer misuse
- DDoS attacks
- External service failures
- Force majeure events
- Customer configuration

## 6. Support

- Enterprise: 24/7 support
- Pro: Business hours
- Free: Community support
- Response times: See support page
