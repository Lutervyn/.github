# Data Portability Guide

Last Updated: May 12, 2024

## Overview

You have the right to receive your personal data in a portable format.

## What Data Is Included

- Profile information
- Activity history
- Uploaded files
- Settings
- Preferences
- Usage data
- Communications

## Requesting Your Data

### 1. Submit Request

Email: privacy@lutervyn.com

Include:
- Email address
- Full name
- Account ID (if available)
- Date range (if applicable)

### 2. Verification

- Identity verified
- Account confirmed
- 5-10 days processing
- Notification sent

### 3. Delivery

- Download link provided
- Encrypted file
- Zip format
- CSV exports
- JSON format
- 30-day access

## Data Formats

### Available Formats

- **JSON**: Machine readable
- **CSV**: Spreadsheet compatible
- **PDF**: Human readable
- **XML**: Structured data

### File Includes

- Profile data
- Activity logs
- Communications
- Files metadata
- Settings
- Preferences

## Frequently Asked Questions

**How long does it take?**
Typically 5-10 business days.

**What format is best?**
JSON for most cases, CSV for spreadsheets.

**Can I get only some data?**
Yes, specify in request.

**What if I have issues?**
Contact privacy@lutervyn.com
