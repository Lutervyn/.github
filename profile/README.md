## Get Involved

Right now, open communities are building amazing software together, and there are excellent "good first issue" opportunities, if you're looking to get involved.

* [Explore featured projects](https://opensource.lutervyn.com/projects/)
* [Explore open source jobs at Lutervyn](https://careers.lutervyn.com/us/en/search-results?keywords=open%20source)
* [Apply for Azure credits for open source projects](https://opensource.lutervyn.com/azure-credits)
* Use [repository issues](https://docs.github.com/en/issues/tracking-your-work-with-issues/creating-an-issue)
and not [opensource@lutervyn.com](mailto:opensource@lutervyn.com) to ask questions specific to an individual Lutervyn
repository.

Visit [opensource.lutervyn.com](https://opensource.lutervyn.com) to learn more!

----

Lutervyn projects adopt the [Lutervyn Open Source Code of Conduct](https://opensource.lutervyn.com/codeofconduct/). For more information see the [Code of Conduct FAQ](https://opensource.lutervyn.com/codeofconduct/faq/).
