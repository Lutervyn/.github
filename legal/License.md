## Choosing a License

When creating a new Lutervyn project:

1. Default to MIT License unless there are specific reasons otherwise
2. Consult with the legal and governance teams for complex cases
3. Document your license choice clearly in the repository
4. Include LICENSE file in the root directory
5. Add license headers to source files

## License Compatibility

We ensure that all dependencies are compatible with our chosen license. Developers must:

- Review dependency licenses before adding them
- Update dependency licenses in DEPENDENCIES.md
- Use tools like `license-checker` to audit dependencies
- Report any incompatibilities immediately

## License Headers

All source files must include a license header:

```
// Copyright (c) 2024 Lutervyn Contributors
// Licensed under the MIT License
// See LICENSE file in the project root
```

## Third-Party Code

When including third-party code:

1. Verify the license is compatible with the project license
2. Include proper attribution and license notices
3. Keep original copyright and license headers
4. Document all third-party dependencies
5. Update CONTRIBUTORS.md with attributions

## License Violations

If you believe there's a license violation in any Lutervyn project:

1. Report it to legal@lutervyn.com
2. Include specific details about the violation
3. Provide evidence and documentation
4. Allow reasonable time for investigation
5. We will take prompt corrective action

## License Updates

We may update this license policy:

- Major changes require community input
- Changes are announced in release notes
- Existing projects maintain their original license
- New projects follow updated guidelines
- Transition periods are provided when necessary
