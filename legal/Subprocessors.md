# Subprocessor Policy

Last Updated: May 12, 2024
Effective Date: January 1, 2024

## 1. Purpose

This policy manages subprocessors who handle customer personal data on behalf of Lutervyn.

## 2. Definitions

**Subprocessor** means any third party processing personal data on Lutervyn behalf.

**Personal Data** means data relating to identified/identifiable individuals.

**Controller** means customer controlling personal data.

## 3. Subprocessor Evaluation

Before engaging subprocessor:

- Security assessment completed
- Privacy controls evaluated
- Insurance requirements verified
- References checked
- Compliance certifications reviewed
- Service level agreement established

## 4. Data Processing Agreement

All subprocessors must:

- Sign Data Processing Agreement
- Accept Standard Contractual Clauses
- Agree to data protection terms
- Accept audit requirements
- Accept incident notification
- Agree to data return/deletion

## 7. Controller Notification

Controllers notified of:

- New subprocessor engagement
- Significant changes to processing
- Changes to data location
- Changes to security measures
- 30 days before implementation
- Via email notification

## 8. Objection Rights

Controllers may object:

- Within 15 days of notice
- To new subprocessor
- For legitimate reasons
- If objection upheld:
  - Alternative offered
  - Terminate relationship
  - Seek alternative solution

## 9. Security Standards

All subprocessors must:

- Maintain SOC 2 Type II
- Or ISO 27001 certification
- Annual security audit
- Encryption at rest and transit
- Multi-factor authentication
- Access controls
- Incident response plan

## 10. Data Transfers

- Standard Contractual Clauses required
- For transfers outside EU/EEA
- Supplementary measures
- Data location specified
- Transfer safeguards documented

## 11. Subprocessor Obligations

All subprocessors must:

- Process per instruction only
- Ensure staff confidentiality
- Implement security measures
- Assist with data subject rights
- Delete data on request
- Notify of breaches
- Allow audits
- Cooperate with authorities

## 12. Audit and Monitoring

- Annual security assessment
- SOC 2 reports reviewed
- Incident reports reviewed
- Performance metrics monitored
- Compliance verified
- Regular check-ins

## 13. Breach Notification

Subprocessors must notify:

- Immediately upon detection
- Detailed information provided
- Remedial actions described
- Impact assessment included
- Recommendations provided

## 14. Termination

Upon termination:

- Data returned or deleted
- As per Data Processing Agreement
- Within 30 days
- Certified deletion
- No further processing
