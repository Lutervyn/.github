# Sales & Customer Onboarding Checklists

Last Updated: May 12, 2026

## 1. Internal Sales Onboarding (For New AEs/SDRs)

### 1.1 Week 1: Foundations
- [ ] Complete HR onboarding and IT setup.
- [ ] Review Lutervyn Mission, Vision, and Values.
- [ ] Product 101: Basic feature overview and value proposition.
- [ ] Tools Access: CRM (Salesforce/HubSpot), Slack, LinkedIn Sales Navigator.
- [ ] Review Sales Processes and Playbook.

### 1.2 Week 2: Deep Dive
- [ ] Detailed Product Training: Live demos and technical deep dives.
- [ ] Competitive Landscape: Strengths/weaknesses vs. competitors.
- [ ] Shadow 5 discovery calls and 3 demos.
- [ ] Practice "The Pitch" with a Sales Manager.
- [ ] Territory/Account list review.

### 1.3 Week 3-4: Ramp Up
- [ ] Conduct first independent discovery call.
- [ ] Pass Sales Certification (internal quiz/mock demo).
- [ ] Set up prospecting sequences.
- [ ] Initial 30-day goals review with Manager.

## 2. Customer Onboarding (Post-Sale)

### 2.1 Phase 1: Kickoff (Week 1)
- [ ] Sales to CS Handover: Document promised outcomes and deal context.
- [ ] Welcome Email: Introduction of CSM and onboarding team.
- [ ] Kickoff Meeting: Define goals, timeline, and key stakeholders.
- [ ] Provisioning: Grant access to production environments.

### 2.2 Phase 2: Implementation (Week 2-4)
- [ ] Technical Configuration: API setups, SSO integration, etc.
- [ ] User Sync: Import/sync user lists.
- [ ] Admin Training: Best practices for system management.
- [ ] Initial Workflow Setup: Create first projects/configurations.

### 2.3 Phase 3: Launch & Training (Week 5-8)
- [ ] End-User Training: Webinars or live sessions.
- [ ] Content Migration: (If applicable) Moving data from old systems.
- [ ] Go-Live: Official rollout to the user base.
- [ ] Post-Launch Check: Identify and resolve immediate blockers.

### 2.4 Phase 4: Success Review (Day 90)
- [ ] Review Success Criteria: Did we meet the kickoff goals?
- [ ] Training Gap Analysis: Are users utilizing key features?
- [ ] Feedback Collection: CSAT survey.
- [ ] Transition to "Adoption" phase.

## 3. Partner Onboarding

### 3.1 Recruitment & Legal
- [ ] Partner Application Review.
- [ ] Signed Partnership Agreement.
- [ ] NDA Exchange.

### 3.2 Enablement
- [ ] Partner Portal Access.
- [ ] Sales Enablement Kit (Slidedecks, Case Studies).
- [ ] Technical Training for Partner Engineers.
