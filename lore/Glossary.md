# Glossary

Last Updated: May 12, 2024

## A

**API**: Application Programming Interface - Interface for software communication
**Artifact**: Build output, typically a container or binary
**Automation**: Automated process execution
**Availability**: System uptime percentage

## B

**Backend**: Server-side application logic
**Backup**: Data copy for recovery
**Branch**: Git version control branch
**Breakpoint**: Debugger pause point

## C

**CI/CD**: Continuous Integration/Deployment
**Cache**: Fast data storage
**Container**: Docker or similar containerization
**Cluster**: Multiple systems working together

## D

**Dashboard**: Metrics visualization
**Deployment**: Moving code to production
**Docker**: Container technology
**Database**: Persistent data store

## E

**Endpoint**: API access point
**Encryption**: Data protection method
**Environment**: Dev, staging, production
**Escalation**: Moving issue to higher level

## F

**Failover**: Automatic backup activation
**Feedback Loop**: Continuous improvement cycle
**Frontend**: User-facing interface
**Firewall**: Network security barrier

## G

**Git**: Version control system
**GitHub**: Git hosting platform
**Grafana**: Metrics visualization tool
**Gateway**: Network entry point

## H

**Hash**: Cryptographic fingerprint
**HTTPS**: Secure HTTP protocol
**Helm**: Kubernetes package manager
**Horizontal Scaling**: Add more servers

## I

**Infrastructure**: Systems and resources
**Incident**: Problem occurrence
**Integration**: System combination
**IP**: Internet Protocol address

## J

**JSON**: Data format
**JWT**: JSON Web Token
**Job**: Scheduled task execution

## K

**Kubernetes**: Container orchestration platform
**Key Pair**: Public/private cryptography
**Keepalive**: Connection maintenance

## L

**Load Balancer**: Request distribution
**Log**: Event recording
**Latency**: Response delay
**Library**: Code reuse package

## M

**Microservice**: Small independent service
**Monitoring**: Continuous observation
**Metadata**: Data about data
**Migration**: Data or system move

## N

**Namespace**: Code organization
**Node**: Compute unit
**Notification**: Alert message
**Null**: No value

## O

**Observability**: System visibility
**Orchestration**: Automated management
**Outage**: Service unavailability
**Override**: Manual exception

## P

**Pod**: Kubernetes container unit
**Patch**: Small fix
**Pipeline**: Automated workflow
**PostgreSQL**: Database system

## Q

**Query**: Data request
**Queue**: Job buffer
**Quota**: Usage limit

## R

**Registry**: Container image storage
**Release**: Version distribution
**Rollback**: Revert to previous
**Route**: Network path

## S

**SLA**: Service Level Agreement
**SLO**: Service Level Objective
**Scaling**: Capacity adjustment
**Schema**: Data structure

## T

**Terraform**: Infrastructure code
**Test**: Quality verification
**Timeout**: Maximum wait duration
**Transaction**: Database operation

## U

**UUID**: Unique identifier
**Uptime**: Service availability
**Upgrade**: Version increase
**User**: System consumer

## V

**Vendor**: External provider
**Version**: Release designation
**Virtual Machine**: Software computer
**Vulnerability**: Security weakness

## W

**Webhook**: Event callback
**Whitelist**: Allowed list
**Workflow**: Process sequence
**Wrapper**: Code abstraction

## X

**XML**: Data format
**XSS**: Cross-site scripting attack

## Y

**YAML**: Configuration format

## Z

**Zero Downtime**: Deployment without outage
**Zone**: Data center region
