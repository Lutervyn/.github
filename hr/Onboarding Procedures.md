# Onboarding Procedures

Last Updated: May 12, 2026

## 1. Overview

### 1.1 Purpose

Onboarding ensures new employees are prepared, engaged, and productive from day one.

### 1.2 Timeline

- Pre-start: 1 week before
- First day: orientation
- First week: foundational training
- First month: integration
- First 90 days: full ramp-up

## 2. Pre-Start Phase (1 Week Before)

### 2.1 Pre-Arrival Checklist

**IT Setup**
- Email account created
- Computer ordered or prepared
- Phone provisioned
- VPN access configured
- Software licenses purchased

**Physical Setup**
- Desk assigned and prepared
- Monitor/keyboard/mouse set up
- Phone line connected
- Internet connectivity tested
- Office access badge ordered

**Administrative**
- Employee file prepared
- Background check final report received
- Drug test (if applicable) completed
- I-9 verification scheduled
- Tax withholding forms prepared

**Communications**
- Team introduction email sent
- Welcome package prepared
- First day logistics confirmed
- Parking/transportation arranged
- Building access info sent

### 2.2 New Hire Paperwork

**Prior to First Day**
- Offer letter signed
- Acceptance confirmation received
- Emergency contact form
- Background check authorization
- Drug testing release (if applicable)

**First Day Completion**
- I-9 verification
- W-4 withholding
- I-9 confirmation
- Employee handbook acknowledgment
- Direct deposit authorization
- Benefits enrollment
- Confidentiality agreement
- Arbitration agreement (if applicable)

### 2.3 Equipment Provisioning

**Computer & Peripherals**
- Laptop or desktop
- Monitor (minimum 24")
- Keyboard and mouse
- USB-C/HDMI adapters
- Laptop stand
- External SSD backup

**Software & Licenses**
- Office 365 subscription
- VPN client
- Slack installation
- Development tools (engineers)
- Adobe Creative Suite (designers)
- Specialized software per role

**Phone & Communication**
- Mobile device (if provided)
- Phone line setup
- Extension assignment
- Voicemail greeting
- Call forwarding configured

### 2.4 Access & Security

**System Access**
- Network login credentials
- Email address and mailbox setup
- Cloud storage (Google Drive, OneDrive)
- Project management tools
- Internal wikis/documentation
- GitHub/development repos
- VPN credentials
- Servers and databases

**Physical Access**
- Badge/keycard issued
- Office entrance access
- Parking access
- Building directory listed
- Restroom keys (if applicable)
- Lock combinations (if applicable)

**Permissions & Policies**
- Data classification training
- Cybersecurity basics
- Password policy explanation
- Device security setup
- Two-factor authentication enabled

## 3. First Day

### 3.1 Arrival & Welcome

**Check-In Process**
- Manager or HR meets employee
- Welcome greeting
- Badge and keys provided
- Parking pass (if applicable)
- Building tour scheduled

**Initial Setup**
- Welcome packet presented
- IT setup assistance provided
- Workspace introduction
- Restroom/break room locations
- Lunch/food options explained

### 3.2 HR Orientation (90 minutes)

**Covered Topics**
1. Welcome and company overview
2. Role and responsibilities review
3. Reporting structure explanation
4. Benefits overview and Q&A
5. Payroll and timekeeping
6. Attendance and time-off policies
7. Code of conduct and policies
8. Confidentiality and IP agreement
9. Emergency procedures
10. Questions and next steps

**Documents Signed**
- Employee handbook acknowledgment
- Confidentiality/NDA
- Arbitration agreement (if applicable)
- At-will employment statement
- Records retention notice

### 3.3 IT Orientation (60 minutes)

**Topics Covered**
- Network login and password
- Email and calendar setup
- VPN access and usage
- Software security and updates
- Backup procedures
- Support contact information
- Two-factor authentication
- Device security
- Data classification
- Acceptable use policy

**Hands-On Setup**
- First login verification
- Email and calendar access
- Slack channel invitations
- File storage access
- Printer/network printer setup
- Phone connectivity test

### 3.4 Department Orientation (90 minutes)

**With Manager**
- Role overview and expectations
- Team introductions
- Workspace tour
- Meeting calendar overview
- First week schedule review
- Key contacts and resources
- Project overview
- Success metrics explanation

**With Team**
- Team members introduced
- Informal socializing
- Lunch together (if possible)
- Team dynamics overview
- Peer support contacts
- Casual Q&A

## 4. First Week

### 4.1 Daily Schedule

**Day 1 (Monday)**
- Morning: HR + IT orientation
- Afternoon: Department orientation
- End of day: Welcome lunch

**Day 2 (Tuesday)**
- 1-on-1 with manager (60 minutes)
- System access verification
- Role-specific training begins
- Meet key team members
- Document access review

**Day 3 (Wednesday)**
- Continued role training
- Documentation review
- Project overview meetings
- Process and procedure training
- Further team meetings

**Day 4 (Thursday)**
- Role training continuation
- Introduce to customers/stakeholders
- Meeting observation/attendance
- First assignment overview
- Feedback and check-in

**Day 5 (Friday)**
- Week recap with manager
- First week feedback
- Next week goals review
- Additional training modules
- Social team activity (optional)

### 4.2 Learning Objectives (Week 1)

Employee should understand:
- Company mission and values
- Team structure and dynamics
- Role responsibilities and expectations
- Key processes and workflows
- Critical systems and tools
- Team members' roles and expertise
- First assignment scope
- Success metrics for role

### 4.3 Resources Provided

- Employee handbook
- Company org chart
- Department/team docs
- Role-specific procedures
- System access guides
- Glossary of terms
- Directory of key contacts
- FAQ document

## 5. First Month

### 5.1 Week 2-4 Focus Areas

**Role Development**
- Complete role-specific training
- Shadow key team members
- Begin first project assignments
- Attend key team meetings
- Participate in team activities

**Integration**
- Meet broader team members
- Understand departmental goals
- Learn cross-functional dependencies
- Attend all-hands meeting
- Join optional social events

**System Mastery**
- Complete all system training
- Proficiency with key tools
- Understand documentation locations
- Learn support processes
- Complete required compliance training

### 5.2 Learning Plan

Created by manager in Week 1:
- Role-specific skills to develop
- Training resources identified
- Timeline for key milestones
- Mentor/buddy assignment
- Weekly check-in schedule

### 5.3 30-Day Check-In

**Timing**: End of first month (Day 30)

**Topics Discussed**
- Progress and accomplishments
- Successes and challenges
- Support provided and needed
- Questions and clarifications
- Comfort level assessment
- Next 60-day expectations
- Feedback exchange

**Documentation**
- Check-in notes recorded
- Progress documented
- Adjustments made to plan if needed
- Manager observations noted

### 5.4 Ongoing Resources

- Peer mentor assigned
- Manager support maintained
- HR support available
- HR check-in at 30 days

## 6. First 90 Days

### 6.1 60-Day Check-In

**Timing**: Day 60

**Topics**
- Progress on role competencies
- Project work review
- Team integration assessment
- Confidence level evaluation
- Support needed going forward
- Identified strengths and areas for growth
- Next 30-day focus areas

### 6.2 90-Day Review

**Timing**: Day 90 (within a few days)

**Review Components**
- Performance against role expectations
- Accomplishments and projects completed
- Team feedback and integration
- Communication and collaboration
- Company culture fit
- Strengths demonstrated
- Areas for continued development
- Continuation decision

**Approval Required**
- Department manager approval
- HR review and sign-off
- All conditions met

**Outcomes**
- Successful completion: continued employment
- Conditional continuation: specific improvements needed
- Termination: role not a fit, poor performance

**Discussion Topics**
- Performance assessment
- Strengths and contributions
- Areas for development
- Career goals
- Compensation review (if applicable)
- Next 90-day priorities

### 6.3 Extended Onboarding

If needed beyond 90 days:
- Extended training period
- Performance improvement plan
- Continued check-ins
- Additional mentor support
- Additional resources

## 7. Specialized Onboarding

### 7.1 Engineering Onboarding

Additional components:
- Code repository access
- Development environment setup
- Build system configuration
- Deployment process training
- Code review process
- Testing procedures
- Debugging tools and techniques
- Architecture overview
- First code contribution

### 7.2 Sales Onboarding

Additional components:
- CRM system training
- Sales process overview
- Pricing and packaging
- Customer management
- Territory assignment
- Account overview
- First sales call observation
- Sales enablement training

### 7.3 Remote Employee Onboarding

Adaptations for remote:
- Virtual office tour (video)
- Frequent video check-ins (daily)
- Asynchronous documentation emphasis
- Virtual team meetings prioritized
- Buddy/mentor more critical
- Mail welcome package if possible
- Consider welcome video call

## 8. Mentor/Buddy Program

### 8.1 Mentor Assignment

- Assigned during pre-start phase
- Senior team member (typically)
- Different department if possible
- Voluntary participation
- 90-day initial commitment

### 8.2 Mentor Responsibilities

- Available for questions
- Informal guidance
- Process clarification
- Cultural introduction
- Lunch/social activities
- Check-ins weekly
- Escalate concerns to manager
- Final assessment at 90 days

### 8.3 Mentor Support

- Mentor training provided
- Mentor guidelines document
- Compensation: recognition or small gift
- Appreciation for service
- Feedback gathered from new hire
