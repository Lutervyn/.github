# Remote Work Policy

Last Updated: May 12, 2026

## 1. Remote Work Overview

### 1.1 Purpose

This policy enables employees to work remotely when appropriate, promoting work-life balance and productivity while maintaining business continuity and collaboration.

### 1.2 Core Principles

- Trust-based arrangement
- Performance-focused
- Flexibility with boundaries
- Communication priority
- Inclusivity in teams

## 2. Eligibility

### 2.1 Employee Eligibility

Eligible for remote work:
- Full-time employees only
- Minimum 6 months tenure
- Current performance rating 2.5 or higher
- Individual contributor or manager level
- Role allows remote work

### 2.2 Non-Eligible Roles

Not eligible for remote work:
- Front-desk/reception staff
- On-site facility needs
- Client-facing in-person roles
- Roles requiring equipment access
- New employees (first 6 months)

### 2.3 Manager Approval

- Remote work requires manager approval
- Business needs considered
- Team dynamics considered
- Can be revoked if performance declines

## 3. Remote Work Arrangements

### 3.1 Hybrid Arrangement (Standard)

**Standard Hybrid Schedule**
- 3 days remote per week
- 2 days in office per week
- Flexibility in scheduling
- Core hours: 10 AM - 3 PM
- Consistent schedule preferred

**Flexible Schedule**
- Manager and employee agreement
- Business needs must be met
- Predictability valued
- 2+ week notice for changes
- No daily commute if fully remote possible

### 3.2 Full-Time Remote

**Eligibility**
- Exceptional circumstances
- Manager + Director approval required
- Business case documented
- Likely not available for most roles

**Expectations**
- Same expectations as in-office
- Timezone alignment important
- Meeting participation required
- Regular communication
- Annual in-office visits possible

### 3.3 Remote Work Agreement

**Required Document**
- Signed agreement before remote work begins
- Specifies days/hours remote
- Performance expectations
- IT security requirements
- Termination conditions

**Changes to Arrangement**
- 2+ weeks notice for modifications
- Mutual agreement required
- Written update to agreement
- Performance impact assessed

## 4. Work Environment Requirements

### 4.1 Home Office Setup

**Company-Provided Equipment**
- Monitor (24" or 27")
- Keyboard and mouse
- Laptop stand
- USB-C/HDMI adapters
- External SSD backup

**Company Reimbursement**
- One-time: $500 equipment allowance
- Desk or table: up to $400
- Chair: up to $400
- Other essentials: within budget
- Receipt submission required

**Employee Responsibility**
- Internet connection: high-speed required
- Backup internet: recommended (mobile hotspot)
- Furniture: basic adequate setup
- Ergonomics: proper posture and setup
- Lighting: adequate for work
- Noise reduction: reasonable quiet environment

### 4.2 Internet Requirements

**Minimum Specifications**
- Download speed: 25 Mbps minimum
- Upload speed: 5 Mbps minimum
- Latency: less than 100ms
- Availability: 99% uptime desired

**Connectivity Issues**
- Proactive communication: notify manager
- Backup internet: mobile hotspot acceptable
- Co-working space: if internet fails
- Office work: if persistent issues
- Reimbursement: internet costs not covered

### 4.3 Workspace Security

**Physical Security**
- Door with lock preferred
- Privacy: minimize distractions
- Confidential materials: secured
- Clean desk policy: when applicable
- No unauthorized access: family/guests

**Cybersecurity**
- Screen visibility: minimize from others
- Video background: professional background
- Microphone control: when not using
- Headphones: for privacy
- Phone security: secured
- Locked computer: when away

### 4.4 Communication Tools

Required tools:
- Slack: primary communication
- Zoom: video meetings
- Email: formal communication
- Project management tool: task tracking
- File sharing: OneDrive or Google Drive
- Backup phone: for emergencies

## 5. Work Schedule & Core Hours

### 5.1 Core Hours

**Required Availability**
- 10:00 AM - 3:00 PM their timezone
- Must be available for meetings
- Synchronous communication during core
- Asynchronous communication outside core

**Timezone Flexibility**
- US timezones: generally supported
- International: case by case
- Communication of schedule: essential
- Meeting scheduling: accommodating

### 5.2 Work Schedule

**Expected Hours**
- Same 40-hour week
- Flexibility in timing
- Breaks taken: normal
- Lunch hour: uninterrupted
- End of day: when assigned tasks complete

**Schedule Variation**
- Start/end times: flexible
- Manager notification: of schedule
- Consistency: preferred
- Changes: 1-week notice
- No automatic schedule flexibility

### 5.3 Availability

**Expectations**
- Responsive during work hours
- Slack status: updated
- Email: checked regularly
- Meetings: attendance expected
- Asynchronous: reasonable response time

**Off-Hours Communication**
- No expectation of response
- Urgent only: contact by phone
- On-call: specific arrangement only
- Vacation: clear communication
- Holidays: standard holiday policy

- Audio quality: clear
- Arrival: on time

### 8.1 Required In-Office Time

**Typical Requirements**
- Tuesday through Thursday: in office

- Illness or medical appointments
- Approved work from home: occasional

- Special circumstances: manager discretion

**Communication Required**
- At least 1 week notice preferred
- Manager approval required
- Calendar update: immediate

- Frequency: monitored for pattern

## 9. IT Security & Compliance

### 9.1 Data Security

**Requirements**
- Encrypted laptop: mandatory
- VPN usage: for all work
- Two-factor authentication: required
- Password management: secure
- Data storage: company systems only
- USB drives: approved encryption only
- Cloud storage: company approved only

### 9.2 Compliance

**Expectations**
- Confidentiality: same as office

- Emails: not continuously monitored

- Isolation: proactively addressed
- Work-life boundaries: intentional
- Burnout risk: monitored
- Communication overload: managed
- Technical fatigue: Zoom fatigue

### 10.2 Support Resources

- EAP: mental health support
- Wellness program: fitness, meditation
- Social events: in-person team building
- Flexible scheduling: balance
- PTO policy: take time off
- Mentorship: available

### 10.3 Work-Life Boundaries

## 11. Performance Issues & Termination

### 11.1 Remote Work Performance

**Monitoring**
- Regular check-ins: with manager
- Project completion: tracked
- Communication: assessed
- Collaboration: evaluated
- Responsiveness: monitored

### 11.2 Performance Improvement

If performance declines:
1. Discussion: with manager
2. Improvement plan: created
3. In-office requirement: may be mandated
4. Support: additional resources
5. Review: at 30-day interval

### 11.3 Remote Work Revocation

Remote work can be revoked if:
- Performance declines significantly
- Business needs change
- Team collaboration suffers
- Communication breaks down
- Compliance issues occur
- 2 weeks notice: typically given

### 11.4 Termination

- Remote work status: does not affect termination
- At-will employment: applies
- Final paycheck: within standard timeframe
- Equipment: returned per standard process
- Access: disabled immediately
