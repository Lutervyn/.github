# Data Protection Impact Assessment (DPIA) Policy

Last Updated: May 12, 2024

## 1. Purpose

Assess privacy and data protection risks before implementing new processing activities.

## 2. When Required

- New processing activity
- Large-scale processing
- Automated decision-making
- Biometric processing
- Healthcare data
- Criminal records
- Special categories

## 3. DPIA Process

### 3.1 Preparation

1. Processing description
2. Stakeholder input
3. Risk identification
4. Mitigation planning
5. Documentation

### 3.2 Assessment

1. Privacy risk analysis
2. Data subject impact
3. Technical measures
4. Organizational measures
5. Residual risks

### 3.3 Review

1. DPO review
2. Management approval
3. Stakeholder consultation
4. Regulators (if needed)
5. Final approval

## 4. Documentation

- Processing description
- Risk analysis
- Mitigation measures
- Approval record
- Review schedule
